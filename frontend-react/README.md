# Terra Relva Frontend React

Nova base do Terra Relva em `React + Vite + TypeScript + Ant Design`.

## Objetivo desta etapa

Preparar a convivência segura entre:

- legado atual na raiz do projeto
- novo frontend em `frontend-react/`

Sem migrar regras de negócio nesta fase.

## Como rodar

```bash
npm install
npm run dev
```
