# Checklist de Qualidade do Terra Relva

## Antes de mexer em funcionalidade

- [ ] Confirmar branch e status do Git
- [ ] Confirmar se há alterações preexistentes
- [ ] Identificar o escopo real da mudança
- [ ] Evitar misturar legado com nova base sem necessidade

## Antes de documentar um módulo

- [ ] Mapear telas existentes
- [ ] Mapear rotas reais
- [ ] Mapear persistência
- [ ] Mapear integração externa
- [ ] Mapear riscos
- [ ] Identificar o que é placeholder

## Antes de alterar comportamento

- [ ] Verificar regra de negócio atual
- [ ] Verificar impacto em outros módulos
- [ ] Checar persistência e migração
- [ ] Checar necessidade de testes
- [ ] Checar necessidade de atualização de documentação

## Antes de publicar

- [ ] Revisar documentação criada
- [ ] Evitar dados sensíveis
- [ ] Evitar arquivos de build e cache
- [ ] Fazer commit seletivo
- [ ] Confirmar status final do Git

## Critérios mínimos de maturidade

- [ ] README raiz útil
- [ ] Roadmap atualizado
- [ ] Auditoria do estado atual
- [ ] Contratos funcionais por módulo
- [ ] Documento de persistência e sincronização
- [ ] Documento de regras de negócio
- [ ] Guia de deploy
- [ ] Checklist de qualidade
- [ ] Decisões técnicas registradas
